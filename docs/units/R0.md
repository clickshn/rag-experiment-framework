# R0 최소판: "어떤 모델을 쓸까" — 단위 계획

상태: 승인됨 (2026-11-17)
관련: docs/design.md §10

## 완료 기준 (설계 §10)

법령 예제(조문 수십 개·문항 20개)로 생성 모델 3개 이상을 **생성만** 수준에서 비교해 품질·비용·속도 표가 나온다. 같은 구성을 다시 돌리면 같은 구성 버전이 나온다. 시험이 GPU 없이 전부 통과한다.

## 범위

R0는 생성만 모드라 Embedder·VectorStore·Reranker·QuestionGenerator는 **Protocol만** 정의한다. 구현은 R0에 필요한 것만 만든다.

| 부품 | 구현 이름 |
| --- | --- |
| Corpus | `law_api` |
| Chunker | `law_article` |
| Retriever | `oracle` |
| Generator | `openai_compat` |
| Judge | `rules`, `llm` |

## 정해 둔 방향 (세부는 해당 단위 메모에서 확정)

- **예제 문항**(U9 전까지 사용자 준비): 20개. 법령은 보조금 관리에 관한 법률, 같은 법 시행령, 국가재정법, 개인정보 보호법. 유형은 조문 번호 4, 개념 4, 여러 조문 4, 조문 참조 3, 답 없음 3, JSON 2.
- **구성 버전**(U2): generator(arm)마다 낸다. 공통 설정과 그 generator를 합친 해시이고, 실행 묶음 해시는 따로 둔다.
- **해시 정규화**(U2): 쓰지 않는 부품은 빼고 `level`은 넣는다. 기본값을 채운 뒤에 넣을지는 U2 메모에서 정한다.
- **실행 기록의 구성 원문**(U2·U6): 치환 전 원문을 저장한다. 리터럴 주소는 마스킹하고 경고한다.
- **클라이언트**(U3): httpx를 직접 쓴다.
- **정답 근거 주입**(U5): gold에 같은 법령의 방해 덩어리를 섞는다(옵션, 기본 켬).
- **인용**(U5·U7): 근거 번호 [n]을 덩어리 ID로 바꿔 계산한다.
- **정오 규칙**(U7): must_min을 채우고 fail이 하나도 없으면 정답이다.
- **판정 수**(U7): R0는 주 판정 1개로 점수를 낸다. 나머지 판정은 기록과 일치율만 표시한다.
- **반복 집계**(U8): 항목 평균, 문항 단위, 반복 간 답이 다른 문항 수를 모두 낸다.
- **로컬 비용**(U8): 벽시계 시간 × GPU 시간당 단가로 계산하고 동시 처리 수를 표시한다. 판정 비용은 따로 낸다.
- **게이트**(실험·검증 모드): R4로 미룬다. R0는 split을 제약하지 않는다.
